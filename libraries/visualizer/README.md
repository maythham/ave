# AVE Visualizer Library

Central library index for the AVE/Visualizer work.

## Source assets

- `ave.txt` — Visualizer element/property reference.
- `sample.viz` — sample Visualizer preset.
- `scene.json` — Visualizer scene.
- `scene1.json` — Visualizer scene.
- `scene2.json` — Visualizer scene.
- `scene3.json` — Visualizer scene.

The original assets remain at repository root so existing paths are not broken. This directory is the canonical library index; source URLs are listed in `manifest.json`.

## Chat handoff

A separate ChatGPT conversation can use this repository as the shared project source. It should fetch `libraries/visualizer/manifest.json` first, then retrieve the referenced source files from the repository.
